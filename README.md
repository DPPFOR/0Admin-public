# 0Admin

0Admin ist ein Self-Operating Geldfluss-Office für SHK-Betriebe.

Das Produkt richtet sich an Betriebe, die offene Zahlungen schneller erkennen, sauber nachhalten und Büroarbeit im Geldfluss reduzieren wollen.

## Status

0Admin befindet sich in der MVP-Phase.

## Hinweis

Dieses öffentliche Repository dient als Produktüberblick. Es ist nicht das operative Hauptrepository von 0Admin.
